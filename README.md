# myschool

SwiftUI-приложение для расписания на понедельник–пятницу.

Откройте папку в Xcode на macOS, создайте iOS App с именем `myschool` и замените основной Swift-файл содержимым `myschoolApp.swift`. Минимальная версия iOS — 16.0. Для иконки используйте `AppIcon.svg`: чёрный фон, белые `ms`.

Приложение использует локальные уведомления: интернет не требуется. Уведомления нужно разрешить при первом запуске. После архивации в Xcode можно экспортировать неподписанный или подписанный IPA, а затем при необходимости переподписать его в eSign 5.0.2.
